notes :

	# C.R.U.D operation :

		C - create --> insert 

			- put items into tables

			- insert fileds
				insert <item> into <table>
		
		R - Read --> select

			- select fields 
				* --> get all the collumns

				collumn_name ---> select the actual collumn

				where --> limit the result of the select
			
			- fields can be combined
			
		U - Update --> alter the table
				
			- Update fields 
				 update <tableName> set <table row> where <collumn_that_changes>

		D - Delete --> delete information from the table
			- Delete field
				delete from <tableName> where <collumn>
